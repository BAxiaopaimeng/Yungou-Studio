# 云构工作室 (Yungou Studio) / 雲構スタジオ

**云构工作室** 成立于 2026 年，是一支由 16 位成员组成的非营利创作团队。我们从零开始构建了“云构平台”，致力于提供稳定、安全、好用的服务。每一位成员都带着自己的热爱与专业技能，共同守护云构。

> **📌 关于更名与版权声明**
> 云构项目早期曾暂定名为“派蒙云”。出于对知识产权的绝对尊重，在向官方咨询并获得不予授权的回复后，团队果断将项目及团队名称正式更名为“**云构工作室 (Yungou Studio)**”。我们始终将合规与版权保护放在首位。

## 🏗️ 云构平台业务总览 (Overview)
**云构（YUNGOU）** 是云构工作室旗下的综合性 Web 平台，一套系统同时运行了**十几个子产品**，覆盖：个人云盘、社交（派蒙信）、AI 聚合网关、音乐库、跳蚤市场、活动中心等。它本质上是一个“多合一门户 + 开发者自用云服务”。

### 核心业务模块：
1. **接入网络**：多线路接入与监控矩阵，保障服务的高可用性。
2. **安全防护**：具备完善的安全中间件链与自研系统级防火墙，时刻保护用户数据。
3. **社交系统（派蒙信）**：包含实名认证、朋友圈、虚拟货币交易，以及实时通信功能。
4. **AI 聚合网关**：配置驱动的多供应商兼容网关，自带熔断机制与每日模型健康测试。
5. **音乐系统**：支持多源接入，内置严格的合作伙伴版权校验与审核流。
6. **跳蚤市场**：完整物品经济系统，带税率计算与每日限购。
